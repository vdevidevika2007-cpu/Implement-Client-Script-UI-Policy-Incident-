# Phase 5 - Project Development

## Project Title
Implement Client Script and UI Policy - Incident

## Development Work

### Client Script
A Client Script was implemented to control the behavior of the Incident form based on the required conditions.

### UI Policy
A UI Policy was configured for the Incident table to control field behavior according to the specified conditions.

### Implementation Steps
1. Open the ServiceNow Developer Instance.
2. Navigate to the Incident table.
3. Create and configure the required Client Script.
4. Create and configure the required UI Policy.
5. Define the required conditions.
6. Configure the required field actions.
7. Save the configurations.
8. Verify the implementation on the Incident form.

## Development Result
The Client Script and UI Policy were successfully implemented in the ServiceNow Incident application.
